仓库管理系统
============

本仓库管理系统是一个综合性的管理平台，支持Web端和移动端操作，涵盖了仓库运营的核心功能模块，包括基础信息管理、销售、采购、配送、拣货、货位和集货位管理等。

## 系统架构
- 后端: C# .NET 10 + Entity Framework Core
- 数据库: MySql (可扩展至其他数据库)
- Web前端: React (响应式设计)
- 移动端: React Native (跨平台iOS/Android)
- 认证: JWT Token-based身份验证

## 功能模块详解

### 1. 基础信息管理
- **产品管理**: 添加、编辑、删除产品信息，包括名称、规格、分类、价格等
- **供应商管理**: 维护供应商信息，联系方式，付款条件
- **客户管理**: 客户资料维护，信用等级，历史交易记录
- **员工管理**: 用户角色分配，权限设置

### 2. 库存管理
- **入库管理**: 采购入库、退货入库、调拨入库
- **出库管理**: 销售出库、调拨出库、报废出库
- **库存盘点**: 定期盘点，盈亏调整
- **库存预警**: 最低库存提醒，过期商品提醒

### 3. 销售管理
- **订单管理**: 创建、修改、取消销售订单
- **报价单**: 快速生成客户报价
- **发货管理**: 订单发货，物流跟踪
- **收款管理**: 应收账款，收款记录

### 4. 采购管理
- **采购订单**: 创建采购计划，供应商选择
- **询价管理**: 多供应商比价，成本控制
- **收货管理**: 采购验收，质量检验
- **付款管理**: 应付账款，付款计划

### 5. 配送管理
- **配送计划**: 优化配送路线，提高效率
- **车辆管理**: 配送车辆调度，维护记录
- **司机管理**: 司机信息，绩效统计
- **配送跟踪**: 实时位置跟踪，客户通知

### 6. 拣货管理
- **拣货单生成**: 根据订单自动生成拣货路径
- **拣货策略**: 按区域、按商品类型等多种拣货方式
- **拣货确认**: 扫码确认，减少错误率
- **异常处理**: 拣货缺货、损坏等情况处理

### 7. 货位管理
- **库区规划**: 设定不同功能区域(收货区、存储区、拣货区等)
- **货位分配**: 自动或手动分配商品存放位置
- **货位优化**: 基于周转率优化货位布局
- **库存定位**: 快速定位商品存放位置

### 8. 集货位管理
- **集货区设置**: 设置临时集货区域
- **集货单管理**: 挌配送路线归集货物
- **集货确认**: 集货完成确认，准备装车
